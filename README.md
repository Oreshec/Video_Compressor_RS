# Video Compressor RS 🎬

Сжатие видео до заданного размера — настольное приложение на **Rust
(eframe/egui)** для Windows. Развитие основной линии; графическая версия предыдущего
поколения (Python + Dear PyGui) живёт в
[`Oreshec/Video_Compressor`](https://github.com/Oreshec/Video_Compressor) и остаётся
рабочим запасным решением — репозитории и данные двух версий полностью раздельны.

## 🚀 Быстрый старт

1. Соберите или скачайте **`VideoCompressor.exe`**.
2. При запуске программа найдёт FFmpeg в `PATH` или в папке `ffmpeg\` рядом с exe.
3. Перетащите видео в окно, укажите целевой размер в МБ, нажмите **«Сжать видео»**.

Готовый файл появится рядом с исходным (`*_compressed.mp4`).

## ✨ Возможности

- **Нативный DPI Windows** (125/150% и т. д.) и нативный drag-and-drop файлов
  из коробки eframe — попадание мыши и курсора совпадает всегда.
- **Адаптивная вёрстка**: панели и скролл от egui, ничего не вылезает за
  пределы окна; док с прогрессом и главными кнопками всегда прижат к низу.
- Константы и математика ядра перенесены 1:1 из проверенной Python-версии:
  - видеобитрейт под целевой размер с запасом (`SAFETY_FACTOR = 0.92`);
  - аудио ограничивается 40% бюджета; совместимое с MP4 умещающееся аудио
    копируется без перекодирования;
  - автоподбор разрешения по битрейту (лестница 2160→1440→1080→720→540→480,
    0.06 битов на пиксель);
  - до 3 попыток с пересчётом битрейта по факту; опциональный **2-pass**;
  - кодеры CPU x264, NVIDIA NVENC, Intel QSV, AMD AMF (детект по
    `ffmpeg -encoders`; режим «авто» и фолбэк на x264 при сбое аппаратного).
- **Отмена** в любой момент; частичные результаты не остаются.
- Настройки — свой профиль: `%APPDATA%\Roaming\VideoCompressorRS\settings.json`.

## 🧪 Разработка

```bash
cargo test            # 16 тестов: математика, парсеры, дымки с реальным ffmpeg
cargo build --release # target/release/VideoCompressor.exe
```

Структура:

```
src/
├── main.rs          точка входа: окно, DPI, шрифт Segoe UI
├── app.rs           вся вёрстка egui и оркестрация задач
├── settings.rs      загрузка/сохранение настроек
└── core/
    ├── presets.rs   константы, пресеты скорости/кодеров, расширения
    ├── bitrate.rs   расчёт планов, авторесолюшн
    ├── probe.rs     ffprobe JSON → MediaInfo
    ├── ffmpeg.rs    поиск ffmpeg/ffprobe, детект кодеров
    └── encode.rs    команды ffmpeg, прогоны, прогресс, отмена
```

## ❓ Как это работает

1. **Анализ** — `ffprobe` возвращает JSON: длительность, разрешение, битрейты.
2. **Расчёт** — целевой видеобитрейт с запасом ~8%; аудио в бюджете не
   перекодируется, если это разрешает контейнер.
3. **Кодирование** — FFmpeg пишет H.264 (`-progress pipe:1` → точный прогресс);
   сбой аппаратного кодера повторяет прогон через x264.
4. **Коррекция** — если размер превысил лимит, битрейт сжимается пропорционально
   превышению и идёт повторная попытка.
5. **Разрешение** — при малых битах на пиксель видео даунскейлится по лестнице.

FFmpeg скачивается отдельно (например,
[gyan.dev](https://www.gyan.dev/ffmpeg/builds/) или
[BtbN builds](https://github.com/BtbN/FFmpeg-Builds/releases)); распакуйте
`ffmpeg.exe`/`ffprobe.exe` рядом с программой в папку `ffmpeg\` или положите в PATH.
